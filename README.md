# Hayat's Design Skills

A Claude Code skill that loads my full web design stack in the right order: taste, motion, 3D and the checks that stop a site looking AI built. It is an index, so the skills it names need installing separately.

Install:

```bash
git clone https://github.com/horror5how/hayat-design-skills ~/.claude/skills/hayat-design-skills
```

Then say "use my design skills" on any web design task.
